# Santy & Caro · 08.02.2027

Invitación web del casamiento en el Teatro El Dorado, Pilar. Sitio estático (HTML/CSS/JS, sin build).

- Ver local: `python3 -m http.server` y abrir http://localhost:8000
- Vista previa de la cuenta regresiva: `?cd=antes`, `?cd=hoy`, `?cd=fiesta`, `?cd=despues`
- Ilustraciones: `assets/img/` (PNG/WebP con transparencia). Para sumar una, poner un `<img>` dentro de su `.ilus` en `index.html`.
- Confirmaciones: completar `RSVP_ENDPOINT` en `assets/js/main.js` para guardar las respuestas.
